# Quick guides / 快速指南

[Home](../README.md) · [中文首页](../README.zh-CN.md) · [Installation](../install/README.md)

## Start a focused project / 从具体项目开始

1. Install Onevium and configure an available AI provider. / 安装并配置可用的 AI 服务。
2. Choose a project directory and create a conversation. / 选择项目目录并新建会话。
3. Describe one clear task and review the proposed work. / 描述一个明确任务，检查结果后继续。

Try the small [development and store-analysis examples](../examples/README.md). They use invented data, so you can explore without connecting a real business account.

## Continue in the documentation / 阅读完整教程

The official site maintains the full product documentation: [English](https://onevium.com/docs/getting-started) · [中文](https://onevium.com/zh/docs/getting-started). This repository keeps short introductions and reusable example prompts, so instructions do not drift between duplicated full manuals.

## Extend with community skills / 使用社区技能

Browse the [skills community](https://github.com/Onevium/onevium-skill-community). Review a skill's instructions and requirements before using it in your project. Community skills are maintained separately from desktop installers.
