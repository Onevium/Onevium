## 更有自己的样子，也更适合长时间使用

1.2.0 重新梳理了会话、侧栏、输入区、设置与预览的视觉层次。更清楚的内容结构、更克制的控件，以及自然衔接的主题配色，让工作区既有个性，也能把注意力留给内容。

暖纸的温和、浅色的清爽、Nord 的沉静、Catppuccin 的柔和——选择适合你的工作氛围。

## 项目有上下文，渠道有来路

研发、运营、研究可以分项目整理；来自飞书、钉钉、Discord、微信的会话也有各自的标识。查看机器人、已连接会话与成员记录，让不同入口的工作更容易找到。

*报表、渠道连接状态、成员及消息数均为演示数据；图示不代表连接了真实店铺或账号。*

## 1.2.0，让常用操作更顺手

- **浏览器记得你的工作。** 每个会话保存自己的访问记录，支持搜索、滚动加载和快捷重新打开。
- **分屏更专注。** 拖拽会话时隐藏可能挡住操作的信息卡；各会话的信息展示独立保存。
- **输入更轻盈。** 地址栏更宽，选中状态更克制，模型筛选也减少了突兀的高亮外框。
- **图表与技能更贴近任务。** 图表展示与编辑体验继续完善；从技能详情进入项目会话草稿，接着补充你的需求。

## 从一个具体任务开始

1. 下载对应平台的[当前安装包](https://github.com/Onevium/Onevium/releases/latest)。
2. 按[使用文档](https://onevium.com/zh/docs)配置账号或模型提供商。
3. 打开项目，试着描述一个具体目标：修改页面、整理报告，或分析一份数据。

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| macOS | Apple Silicon / Intel | DMG |
| Windows | x64 | EXE |

升级方法与已知限制，请阅读所下载版本的发布说明。
