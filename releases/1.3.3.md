# Onevium 1.3.3 — Space, browser recordings, and smoother AI collaboration

[简体中文说明](1.3.3.zh-CN.md)

Onevium 1.3.3 introduces Space, bringing documents, tables, presentations, webpages, and their discussions together in the chat workbench. This release adds Fable 5.2, GPT-6.1 Terra, and GPT Image 2.6 support, alongside browser recordings, live confirmations in the menu-bar hub, and Ultrathink for the current turn.

## Models and thinking controls

- **Fable 5.2.** Added model selection, thinking-effort controls, and usage pricing, with an updated bundled Claude runtime for the new model. Five effort levels run from low to max, with medium as the default. Supported Claude connections also offer one-turn Ultrathink and a separate collaboration control.
- **Mythos 5.2, GPT-6-Cyber, and GPT-6 Rosalind.** Added catalog entries, supported capability information, and usage pricing, with provider-approval indicators. These models are disabled by default; enable them after obtaining account access.
- **GPT-6.1 Terra.** Added model selection, thinking-effort controls, image-input support, and tool-call handling. Tool calls use a Responses connection.
- **GPT Image 2.6 Flare / Sunburst.** Added to image-creation model choices with their generation options and pricing information.
- **GPT-6 Astra and Kimi.** Older OpenAI connections receive a missing Astra entry and updated effort choices. Newly created Moonshot connections use Kimi K3.1 Pro for fast and subagent roles, while existing model mappings and personal settings are preserved.
- **Separate thinking and collaboration controls.** The composer keeps its thinking-effort slider and places one-turn Ultrathink and automatic collaboration in advanced options. Available controls follow the selected model and connection, and an explicit collaboration-off setting is respected.

## New features

- **Space: a home and history for your resources.** Create spaces, import resources, edit Markdown documents, add comments, and browse versions. Each resource opens independently and owns its attachments and related discussions. Resources saved from a conversation can outlive that conversation. Reference a whole resource or selected text in chat, and use session information to see resources that were referenced, read, changed, or saved.
- **Tables, tasks, and Office files.** Organize information and tasks with native tables, typed fields, records, and views. Review field mappings before importing Excel data. Spreadsheets and presentations support selected editing operations, saved versions, and previews. Complex Office content retains its original file, with editing or preview according to the supported format; this is not full Office editing compatibility.
- **Save interactive webpages.** Webpage resources retain an entry file and supporting files, with file inspection, previews, version history, and related discussions for repair requests. Saved snapshots are distinguished from external resources requested when a page runs.
- **Resources in the chat workbench.** Open Space beside your conversation and use the resource's editing, comments, versions, and previews. Input state follows the relevant resource or conversation. Saved changes refresh the corresponding content while preserving unsaved local edits.
- **Built-in browser recordings.** Record the current tab, pause, resume, stop, and save. Recording pauses when its tab is no longer visible. Manage recordings in storage settings. A recording lasts up to 15 minutes and also has a file-size limit. This records the browser page, not the whole desktop or audio.
- **Confirmations and one-time codes in the hub.** Review and resolve live confirmation requests directly from quick access. Add time-based verification codes from setup keys, QR images, or batch imports, including supported Google Authenticator exports. Review the destination secret item for each account before importing.
- **Unified permission and confirmation settings.** Set waiting times and timeout behavior by category, including tools, browser, vault, and SSH, with quick access from confirmation cards. Channel full-access mode executes operations from admitted messages immediately while preserving existing bot modes and sender checks.
- **Conversation management and run history.** Within existing permissions, AI can create, stop, trash, or restore conversations. Session information shows agent history, linked scheduled-task results, and navigation to the actual runs.
- **Connected task sources.** Native Space tables can connect to conversation tasks and authorized Feishu tasklists, calendars, and DingTalk Todo sources. Manage sources, pull records, and write completion status back where supported.

## Daily reviews in Space

The community now includes the official **Daily review** skill. It learns writing preferences from a small sample of recent conversations and your explicit feedback, summarizes results, decisions, and next steps, and keeps reusable lessons in Space. Reviews retain their sources and remain editable. Add a scheduled task to run the workflow at a time you choose.

After installation, try: “Create a Work Review Space collection. Learn my communication preferences from recent conversations, then save today's concise review and supported lessons to Onevium Space.”

## Improvements and fixes

- More stable long replies and session switching, with less flicker on the first send. Feedback distinguishes a rejected steering request from a message that is still queued.
- More compact child-session cards with model and provider details, easier access to recent children, and removal of the fixed per-parent child-session count limit.
- A shared Markdown editing experience across documents and file previews, with fixes for list selections, table input, layout changes, and document switching. Diagrams can open in a full-window view.
- Fixes for settings load/save races so late responses do not replace newer edits. Incomplete reads preserve drafts and show an error. Concise user-rule presets and clearer tool-loading explanations are also available.
- Better browser identity, autofill, and download handling, plus a fix for credential checks that could freeze Windows sessions.
- Image creation, AI tools, and background image jobs share a generation queue, with batch requests and bounded rate-limit retries. Temporarily unreadable credentials produce accurate feedback instead of being reported as missing configuration. Nano Banana Pro aspect-ratio choices are corrected, and image, text, and thinking usage are distinguished using provider-reported information.
- The browser remembers the last successfully used identity, and each new identity request gets its own countdown. Verification-code details support metadata edits and batch actions while preserving unselected items and existing sign-in information.
- Settings is accessible from the navigation rail and account menu, with common settings such as Tools and Proxy opening in place.
- Fresh installs can begin Claude sign-in through the bundled runtime and start with the built-in browser and more tool groups enabled. New appearance, naming, and tool defaults do not overwrite existing users' preferences.

## Before upgrading from 1.3.2

- **The first launch upgrades the main database.** Onevium creates and verifies a pre-upgrade backup before migrating local data. Let startup finish without forcing the app to quit. Version 1.3.2 cannot directly open the upgraded main database.
- **Keep a pre-upgrade copy of your data.** Upgrade backups are under `upgrade-backups` in the active data directory. To roll back, fully quit Onevium, save a separate copy of the current data, restore `onevium.db` from the pre-upgrade backup, and move aside the old `onevium.db-wal` and `onevium.db-shm` files before starting the older version. Changes made to the main database after the upgrade will not be retained by this rollback.
- **Include Space in a complete backup.** Space has its own database, files, and versions in the data directory's `space` subdirectory. The existing database-backup feature backs up the main database; it is not a complete Space backup. For device migration or a beta rollback, fully quit the app and back up the whole data directory rather than a single database file.
- **A replacement for Daily Briefing.** The built-in Daily Briefing and its dedicated scheduled trigger have been retired, with historical rows retained in the database. Install the official community [Daily review skill](https://github.com/Onevium/onevium-skill-community#每日复盘--daily-review) to learn your writing preferences and save personalized work recaps and evidence-backed lessons in Space. Add a scheduled task with your preferred time, project scope, and model for daily runs. Initial setup is required; existing briefing schedules are not migrated automatically.
- **Review Permissions and confirmations.** With no new policy saved, ordinary confirmations default to automatic confirmation after 30 seconds, and questions default to using an available default choice after two minutes. Required input is never invented. An existing vault timeout-deny preference continues to apply to vault, SSH, and sensitive actions. Change waiting time and confirm/deny behavior by category. These rules do not authorize an untrusted source or channel sender. A channel configured for full access executes operations from admitted messages immediately.
- **Models and personal preferences.** New catalog additions preserve existing model selections, custom settings, and disabled rows. Unused, uncustomized restricted catalog entries may be disabled by default; enable them manually after checking account access. Fresh-install tool and appearance defaults are not imposed on existing users.
- **macOS updates.** Official 1.3.2 and 1.3.3 packages use the same fixed Onevium signing identity. Differential updates can reuse unchanged blocks when the old cache and blockmaps are available, with full-download fallback. Older ad-hoc builds need one manual installation. Check for updates in the app. For a manual installation, fully quit Onevium and replace it with the official DMG. Keychain access may need to be allowed again on first launch.

## Supported scope

Space focuses on local resources and does not provide cloud coediting. File reading and AI references have format and size limits. Scanned or encrypted PDFs, complex embedded Office content, and audio/video analysis must not be treated as fully read. External sources such as Feishu and DingTalk require separately configured connections and upstream permissions.
