# Onevium 1.2.2 — Files, background work, and MCP controls

Onevium 1.2.2 brings more file work into the conversation, improves background sessions and MCP controls, and expands the optional model catalog.

- **Files in the workspace:** open local file references from chat. Edit Markdown, text, and CSV files, with a grid preview for CSV. Preview PDF, Word, PowerPoint, and Excel files in read-only mode.
- **Attachments:** paste, drop, or select files with more consistent references. Re-editing a queued message preserves its text and original images.
- **Background work:** tasks and child conversations continue after the main conversation is interrupted. Child conversations stay grouped with their parent, and concurrency counts active work.
- **MCP controls:** set availability by global, project, or conversation scope; choose allowed tools and on-demand loading, inspect schemas and estimated context cost, and export a CLI configuration.
- **Review:** compare branches across repositories with clearer previews, smoother repository switching, and more reliable comments and navigation.
- **Models:** optional entries add Grok 4.7, Claude Opus 5.5, and GPT-6 Sol and Luna. Model routing and saved custom choices receive compatibility fixes.
- **Browser control:** improved form inputs, dates, dialogs, first-page loading, and actions on background views. Console and network records are easier to inspect, and the operating state remains visible through the chat turn.
- **Everyday fixes:** repair automatic titles that contained attachment references, improve per-turn cost records and channel conversation naming, and preserve dictation when switching conversations.
