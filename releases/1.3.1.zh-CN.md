# Onevium 1.3.1 — 秘钥库与 SSH 主机、独立图像页、更顺滑的回复

Onevium 1.3.1 新增秘钥与主机管理，让 AI 在授权范围内使用凭据和 SSH 服务器；图片创作有了独立页面，长会话、渠道审批、Windows 启动和更新也有多项改进。

- **秘钥与主机：** 在设置中集中管理服务器、数据库、API 和云账号凭据，按分类和标签整理。AI 按引用使用条目，由 Onevium 在执行时填入秘钥并遮蔽输出中的已知秘钥。支持从现有文件和 CLI 配置导入；AI 使用默认关闭，需要手动开启。
- **SSH 与授权：** 经授权后，在 SSH 服务器上执行命令、读写文件，支持密码、私钥、SSH agent 和 OpenSSH 配置。授权卡可选择一次、限时或本会话，也可设置免询问时段；生产环境条目和高风险操作有额外限制。普通请求的无人响应策略默认为两分钟后允许一次，可在设置中改为拒绝。
- **验证码与渠道请求：** 保存和填写两步验证码，在 SSH 登录或内置浏览器中使用。渠道会话支持处理部分秘钥授权请求；生产环境秘钥、凭据文件和需要输入内容的请求仍须在电脑上确认。
- **独立图像页：** 从导航栏进入图像创作，选择模板、风格、图片服务和尺寸，在「我的作品」中查看结果、标注、对比版本并继续修改。生成失败时显示原因，并提供重试或重新保存入口。需要另行配置图片服务。[图片生成与画布](https://onevium.com/zh/docs/image-creation)
- **回复与会话：** 逐词文字效果和卡片入场更顺滑，改善长回合、分屏和大段差异的显示；回复完成与过程收起时更稳定。未发送的文字和附件可在重启后恢复，此前版本遗留的草稿不会自动恢复。
- **上下文与听写：** 新增 Claude Code 自动压缩时机设置，Claude Agent SDK 升至 0.3.302；听写栏可在转录完成后直接发送。无法解析的 Claude Code 设置文件会拒绝保存，避免覆盖原有内容。[语音听写](https://onevium.com/zh/docs/voice-dictation)
- **自动化与渠道：** 定时任务显示并允许修改 Auto / 完全访问权限；渠道审批更准确地对应原会话和请求，展示的命令遮蔽密码、令牌等敏感值。机器人访问设置改动需要在桌面确认。[定时自动化](https://onevium.com/zh/docs/scheduled-runs) · [渠道指南](https://onevium.com/zh/docs/team-channels)
- **启动与更新：** 修复 Windows 登录检查卡住的相关问题，更新安装失败后恢复工作区并提供手动下载；安装程序先关闭运行中的 Onevium 再替换文件。另修复网页模式版本比较、工作树选择、终端焦点和设置保存问题。

## 升级前请了解

完整升级步骤与恢复说明：[安装与更新 Onevium](https://onevium.com/zh/docs/installation#updates)。

- **不支持降级。** 1.3.1 会先备份本地数据库，再升级数据格式；1.3.0 及更早版本无法直接读取。备份位于数据目录的 `upgrade-backups` 中。
- **macOS 手动更新。** 应用使用 ad-hoc 签名，未经 Apple 公证，无法在应用内自动替换。请先退出 Onevium，再下载对应芯片的 DMG 替换应用。保持同一芯片版本，跨 Intel / Apple Silicon 改装可能需要重新填写服务商 API Key。
- **1.3.0 的 Mac 更新提示。** 如果已点「下载并安装」，不要继续点「重启以更新」；它无法完成替换，窗口可能消失。已遇到此情况时，从程序坞退出 Onevium，再手动安装 DMG。
- **登录与系统权限。** 从 1.2.x 升级请保持联网，完成许可证验证；首次使用相关功能时可能再次出现钥匙串或系统权限提示，请按实际用途确认。
- **默认权限变化。** 旧定时任务中保存为默认权限的任务会改按 Auto 模式运行，可在任务详情中调整。渠道机器人需要在「渠道」中确认设置后重新连接；秘钥与主机的 AI 使用需手动开启。
- **Windows 安装。** 可以通过应用内更新或运行下方安装程序升级。安装程序未做代码签名；仅在确认来自官方且校验一致后处理系统拦截提示。Windows 的安装、启动和覆盖升级尚未在真实 Windows 环境验证。
