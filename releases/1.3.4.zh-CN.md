# Onevium · 1.3.3 → 1.3.4 完整升级清单

[English](1.3.4.md)

## 会话列表与分屏

- 侧栏可按状态、连接下的模型和时间查找会话。筛选时保留所属项目和父会话，展开空项目会显示原因。有未读或待确认事项时出现快捷入口。处理一项后，它会保留到离开当前列表，新到事项追加在末尾。
- 切到手动排序后，可拖动同级会话，或在置顶和普通项目各自的分组内调整项目顺序。主动新建的会话或项目排到相应分组前面，重开后保留顺序。按住 Shift 拖动会话可打开分屏。
- 工作树标记跟随所属会话。侧栏各入口的标题对齐，长标题列表滚动和调整宽度时更平稳。窄分屏中的消息索引留在边缘，鼠标和键盘仍可跳转到指定消息。

## 实时回复与代码

- 运行时直接显示最近的进展文字和工具操作。长任务逐步折叠较早的步骤。正常完成并出现最终答复后才收起过程。中断、失败或只有工具结果时，保留最近进展。手动展开长过程可连续滚动，上下渐隐提示还有内容。
- 运行摘要整行扫光，命令数、查看数和技能数随进度更新，等待批准的操作单独标明。展开、收起和快速反向点击过渡更平滑，并遵循减少动态效果设置。文件改动先显示增删行数，点开才显示差异。
- 回复结束时，段落、代码块和阅读位置保持稳定。上滚查看旧内容或操作另一分屏时可继续停在原处。复制代码保留换行和空行，代码折行、展开选择及键盘焦点也能从实时回复延续到历史消息。快速输出时主要刷新正在增长的文字。
- 下一轮实际使用了不同模型时，对话中会标出前后模型。已展开的错误详情在回复结束后继续显示。重新打开会话仍有错误码，模型不可用时会提示核对上游模型 ID 和推理档位。

## 暂停、中断与恢复

- 退出应用或重启安装更新时，会先保存已收到的回复并暂停本地任务。下次启动会尝试继续符合条件的退出、更新或异常中断任务，带回原会话及运行模式。主动停止的任务保持停止，原有权限确认继续生效。
- 暂停会话的空输入框提供「继续」。输入文字或加附件后可直接发一条新消息。排队的消息会等待明确的操作，重复点击或重试会沿用同一次发送。中断回合显示已回传的 token，用量不全时标明「最终费用未回传」。

## 内置浏览器与录制

- 地址栏可直接搜索，支持停止加载和浏览器快捷键。Command+F（Windows 为 Ctrl+F）在右上角打开页内查找，可查看匹配数并跳转，网页位置保持稳定。「浏览器记录」可搜索当前或所有会话的标签页和历史，也可按文件名查找下载。
- AI 操作网页时，可从底部「接管」，保留已填内容，暂停该页正在执行和排队的 AI 操作。点击「允许 AI 操作」后再交还。浏览器回收标签资源时会保护未完成的表单、编辑和播放中的媒体，保留独立弹窗与标签页标注。标注保存失败可重试。
- 下载列表保留状态，可打开文件、定位到文件夹、取消或重试适用的下载。文件被移动或删除时会提示。修复恢复附件页时反复下载、同名文件冲突和保存位置不可用时的问题。
- 录制当前标签页时，可指定时长，到点自动停止并保存。计时、停止和接管控件悬浮在底部，录制边缘提示、工具栏和聊天界面均在成片之外。切走隐藏标签页时暂停录制，成片仅含所选网页画面。

## 资料空间、文件与图表

- 资料库优先显示已保存的内容。页面模板和只读指南可从创建入口打开。大资料库分页加载，重试时保留已加载条目，打开资源再返回时保留阅读位置和分类。创建、重命名、移动以及关联讨论在刷新时更稳定，Excel 会导入到已选择的资料空间。
- 打开 Office 版本历史前会先保存待写入的编辑。可预览历史文件，读取或恢复失败时可重试。载入外部版本后重设撤销状态。资料空间的文本文档和文件标签页新增「复制全文」，包含当前草稿，并读取支持范围内的完整长文件。
- 选择或拖选表格单元格时视口更稳定，长值在工具栏内部滚动，键盘和搜索仍会定位目标。PDF 在缩放时保留上一帧直到新画面就绪，演示文稿随面板宽度适配。拖动分隔线时，嵌入式预览不会抢走拖动。
- 聊天、画布、文件阅读器和富文本编辑器复用 Mermaid 图表渲染结果。思维导图首次打开时会更好地适应视口，切换页面、编辑源码或更换主题后减少重复布局和过期预览。代码编辑器的底色与语法颜色跟随工作区主题。

## 对话模型与 1M 上下文

- OpenAI 新增 GPT-6.2 Astra 和 GPT-6.2 Sol，支持图片输入、五档推理（Low 到 Max）和长上下文计价。工具调用使用 Responses 连接。新建聊天服务默认启用一个推荐模型，可展开其他选项。预设角色可继承可用模型，已有连接、禁用项、自定义映射和固定会话保留原选择。长模型弹窗也能在窗口标题栏下方正常关闭。
- 支持 1M 的官方 OpenAI、Gemini 等模型默认使用已识别的上下文窗口，主会话和子任务按各自模型生效。旧连接也可按保存的角色识别。较小窗口、手动关闭或自定义连接明确配置的限制继续有效。
- 智谱国内与国际 Coding Plan 新增 GLM-5.4，支持图片输入、1M 上下文和 Low、High、Max 三档推理。新建连接推荐 5.4，旧连接可在模型管理中启用。用量面板显示套餐积分规则，自定义价格优先。GLM-5.3 和 5.3-Flash 仍可选。新建国内预设的自动压缩窗口为 512,000 tokens，国际预设为 1,000,000。两者的模型上下文均为 1M。

## Gemini 推理、服务档位与图像

- Gemini 4 新增 Carbon、Hydrogen 和 Neon，并补齐已有 Argon 的上下文与计费信息。Carbon、Argon 提供 Low、Medium、High。Hydrogen、Neon 另有 XHigh（更深）。官方接口发送结构化推理参数，兼容的 Antigravity 网关会按当前连接实际列出的模型 ID 匹配档位。
- 可按模型选 Standard、Flex 或 Priority。1.3.4 内置的输入与输出标准倍率分别为 1×、0.5×、1.8×。默认按服务实际返回的档位和对应费率估算，可用自定义倍率覆盖。长回复续写按各次请求核算，真实 token 数独立显示，无法确认时标明费用未知。
- 四款已有的 Nano Banana 图像模型在设置、生成和参考图编辑中使用各自的画幅、参考图上限、分辨率与计价规则，已保存的选项可在重启后继续使用。用量按生成尝试记录，费用估算优先使用自定义倍率。
- Nano Banana 2.1 提供 Minimal、Medium（默认）、High，输出 1K、2K 或 4K。Nano Banana 2 提供 Minimal（默认）、High，另支持 512 输出，也可选 1K、2K、4K。
- Nano Banana 2 Lite 提供 Minimal（默认）、High，输出 1K。Nano Banana Pro 由模型管理推理，输出可选 1K、2K、4K。

## 设置与秘钥库授权

- 修改 CLI 即时设置时只更新所选字段，保留正在编辑的 JSON 草稿和其他设置，并校验权限与环境变量。保存的思考默认值用于实际请求。快速切换语音偏好时以最后一次选择为准。浏览器身份即使没有打开标签页也可清理数据，失败会提示。移除已退役的工具评估设置，记忆模型与预算仍可配置。
- 秘钥库可对符合条件的条目查询和已验证的 SSH 文件读取选择「记住直到退出 Onevium」。记忆绑定同一来源、凭据、目标与操作，可分别授权本机、指定渠道或定时任务。锁屏或休眠时暂停使用，停止授权或退出应用后清空。

## 桌面启动、更新与升级须知

- 更新可在后台下载，角落显示进度，下载完成后由你选择重启安装。macOS 启动期间再次点击 Dock 或从菜单栏打开工作区，会回到同一扇就绪窗口。Windows 改进普通启动时主窗口的显示，并使用不透明窗框。
- 从 1.3.3 升级前，退出应用并备份完整数据目录，包含资料空间文件、版本和录制。首次启动会备份并校验主数据库，再迁移会话和设置。回退到 1.3.3 需要恢复升级前的数据副本。模型目录升级后的数据库启动兼容性也已修复。
- 本版提供 macOS Apple 芯片、macOS Intel 和 Windows x64 三种安装包。两种 macOS 包沿用 1.3.3 的 Onevium 签名。同版本号的临时签名测试包需手动用官方 DMG 替换一次。支持差量更新，旧缓存或块图不可用时可完整下载。
