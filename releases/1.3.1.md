# Onevium 1.3.1 — Secrets and SSH hosts, a dedicated Images page, and smoother replies

Onevium 1.3.1 adds secrets and host management so AI can use credentials and SSH servers within the permissions you grant. Image creation gets its own page, with improvements to long conversations, channel approvals, Windows startup, and updates.

- **Secrets and hosts:** manage server, database, API, and cloud credentials in Settings, organized by category and tags. AI uses references to entries; Onevium fills in secrets at execution time and masks known secret values in output. Import existing files and CLI configurations. AI access is off by default and must be enabled explicitly.
- **SSH and approvals:** authorize commands and file operations on SSH servers using passwords, private keys, SSH agent, or OpenSSH configurations. Approve once, for a period, or for the conversation, with optional periods without prompts. Production entries and high-risk operations have extra restrictions. Ordinary requests default to allowing one use after two minutes without a response; this can be changed to deny in Settings.
- **One-time codes and channel requests:** save and fill authenticator codes for SSH sign-in or the built-in browser. Supported channel conversations can handle some secret approval requests; production secrets, credential files, and requests requiring input still need confirmation on the computer.
- **Dedicated Images page:** choose templates, styles, an image service, and dimensions from the navigation rail. Browse results in My creations, annotate, compare versions, and continue editing. Failed requests show a reason and offer retry or save-again actions. Requires a separately configured image service. [Image generation and canvas](https://onevium.com/docs/image-creation)
- **Replies and conversations:** smoother word-by-word text and card entrances, better display of long turns, split conversations, and large diffs, and more stable positioning when replies finish or process details collapse. Unsent text and attachments survive a restart; drafts left by earlier versions are not recovered automatically.
- **Context and dictation:** choose when Claude Code compacts long conversations, with Claude Agent SDK updated to 0.3.302. Dictation can send immediately after transcription. Saving an unreadable Claude Code settings file is refused to preserve its existing contents. [Voice dictation](https://onevium.com/docs/voice-dictation)
- **Automations and channels:** scheduled tasks display and let you change Auto / Full Access permissions. Channel approvals match the originating conversation and request more accurately, and displayed commands mask passwords, tokens, and other sensitive values. Changes to bot access settings require desktop confirmation. [Scheduled automations](https://onevium.com/docs/scheduled-runs) · [Channel guide](https://onevium.com/docs/team-channels)
- **Startup and updates:** fixes for Windows getting stuck at sign-in checks, workspace recovery and manual downloads after failed update installation, and closing the running app before replacing files. Also fixes web-mode version comparison, worktree selection, terminal focus, and settings saves.

## Before you upgrade

Full upgrade steps and recovery notes: [Install and update Onevium](https://onevium.com/docs/installation#updates).

- **No downgrade.** 1.3.1 backs up the local database before updating its format; 1.3.0 and earlier cannot read the upgraded data directly. Backups are stored in `upgrade-backups` under the data directory.
- **Manual macOS update.** The app uses an ad-hoc signature and is not notarized by Apple, so it cannot replace itself through the in-app updater. Quit Onevium, then download the DMG for your chip and replace the app. Keep the same architecture; switching between Intel and Apple Silicon builds may require entering provider API keys again.
- **The 1.3.0 Mac update prompt.** If you already chose Download and install, do not continue with Restart to update: it cannot replace the app, and the window may disappear. If this happened, quit Onevium from the Dock and install the DMG manually.
- **Sign-in and system permissions.** Stay online for license verification when upgrading from 1.2.x. First use of some features may prompt for Keychain access or system permissions again; confirm according to your intended use.
- **Changed permission defaults.** Older scheduled tasks saved with default permissions now use Auto; adjust them in task details if needed. Confirm channel bot settings in Channels before they reconnect. AI access to secrets and hosts must be enabled manually.
- **Windows installation.** Update in the app or run the installer below. The installer is unsigned; only handle system warnings after verifying the official source and checksum. Installation, startup, and upgrades over an existing version have not been tested on a real Windows environment.
