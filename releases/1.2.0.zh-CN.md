# Onevium 1.2.0 — 让工作，看起来更清楚

**面向 macOS 与 Windows 的重大界面更新**

1.2.0 是一次围绕日常工作的重大界面重构。我们重新梳理了从项目侧栏、会话内容、输入区，到浏览器、设置与信息面板的视觉层次，让经常使用的功能拥有更一致的表达，也让每一处内容有更合适的位置。

它带来的是一个更清晰、更有个性，也更适合持续工作的 Onevium。

## 一个更完整的工作界面

新的视觉体系贯穿会话与工作区。主题配色、文字层次、间距和控件状态相互配合：浏览复杂内容时更容易抓住重点，日常输入和切换时也少一些突兀的视觉干扰。

- 多套内置配色，兼顾浅色与深色工作氛围。
- 重整会话、项目、设置与预览的界面层次。
- 地址栏和模型筛选采用更克制的选中效果。
- 调整 macOS 顶部侧栏图标的尺寸基准、线条与对齐。

## 浏览器，跟着当前工作走

页面与会话之间的联系变得更清楚。打开过浏览器的会话拥有自己的快捷入口，之前访问的页面更容易找回。

- 会话独立保存访问记录；搜索标题或网址，滚动加载更多。
- 权限旁的浏览器入口可以查看记录并重新打开页面。
- 会话信息中也能查看浏览记录。
- 更宽的地址栏，以及统一的加载、超时、无法访问等状态页面。
- 修复访问失败后，重试同一网址可能没有真正重新加载的问题。

## 分屏与会话，更顺手的细节

拖拽、切换和查看信息，是每天都会发生的小动作。1.2.0 继续打磨这些细节，让界面更好地配合当前操作。

- 拖拽会话和调整分屏顺序时，信息浮层及时让出操作区域。
- 每个会话独立保存信息卡的显示状态。
- 完善模型选择保持、偏好持久化和新会话输入区布局。

## 图表、技能与设置，继续完善

- 改善 Mermaid 图表加载体验，支持放大与源码画布编辑。
- 重整插件中心与设置界面，方便查找和管理能力。
- 从技能详情进入所选项目的会话草稿；先编辑需求，再由你发送。
- 完善原生模型的用量统计与推理能力配置。

## 看看它如何融入工作

研发场景可以把页面修改与浏览器预览并排；电商场景可以把简短分析与图表放在一起。已有的飞书、钉钉、Discord、微信渠道能力，也能在项目与渠道视图中展示各自的上下文。

[查看界面与场景图片](https://github.com/Onevium/Onevium/blob/main/README.zh-CN.md)

这些场景使用模拟数据，展示的是工作方式。渠道接入和 Fable 5.1 并非本次首次提供的能力。

## 升级与可用性

1.2.0 是原计划 1.1.24 的正式版本号。请选择 macOS 苹果芯片 / Intel 的 DMG，或 Windows x64 安装程序。macOS ZIP 和 Windows blockmap 继续用于更新链路，Windows 保留差分更新格式。

升级前结束正在执行的任务并退出应用，保留原操作系统账户与数据目录。启动时自动迁移会话与设置；已有数据库需要升级时，会先在本地 `upgrade-backups` 生成一致性快照。请勿手动清空应用数据。回退旧版不等于无损降级：旧版本可能丢弃新增浏览历史，恢复数据库快照会丢失快照之后的改动。

这次还优化了重会话切换：先呈现目标上下文，再分批加载较重的历史内容。Agent 卡片在压缩高度的同时保留实际进度；外部接入首次引导、服务编辑滚动、暗色浮层细边界和输入焦点样式也一并完善。

**兼容说明：** macOS 安装包未公证，请按官网安装指南处理系统确认；本次未使用个人开发者证书。Windows x64 安装包和更新元数据经过打包检查，但本次 macOS 构建环境未实测 Windows 旧版到新版的差分安装。特别大的单条消息仍可能需要一定渲染时间。
