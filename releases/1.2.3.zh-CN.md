# Onevium 1.2.3 — 文件改动卡片与独立文件窗口

Onevium 1.2.3 会列出每次请求改了哪些文件，可在独立窗口中打开本地文件，并打磨了日常聊天细节。

- **本轮文件改动：** 每条回复列出本次改动的文件，可实时预览、安全恢复；一键在 Review 面板打开，并可在"本轮改动"和"当前工作区"之间切换。卡片可在设置中隐藏，记录与恢复不受影响。
- **独立文件窗口：** 可在 macOS 和 Windows 中把 Onevium 设为"打开方式"。可编辑 Markdown（实时预览）、纯文本、CSV 和常见代码与配置文件；可预览 HTML、SVG、PDF（10%–400% 缩放）、Word（.docx）、PowerPoint（.pptx）、Excel（.xlsx）、图片、视频和音频。
- **聊天更顺滑：** 工具操作和输出状态不再闪烁，截图发送后立即显示，子智能体收成一行头像，分屏标题栏和消息缩略导航更简洁。
- **浏览器设置更清楚：** 只有选择"外部"时才显示外部 Chrome 连接，每个浏览器选项都说明了实际作用。
- **稳定性：** 修正恢复对话后的用量记录，频道在应用重启后自动重连，面板切换更顺滑。
