# Onevium · Complete upgrade notes from 1.3.3 to 1.3.4

[简体中文](1.3.4.zh-CN.md)

## Finding and arranging conversations

- Filter conversations by status, by model within a connection, or by time. Results retain their project and parent conversation, and an expanded empty project explains why it has no matches. Unread and approval shortcuts appear when relevant. Rows stay in the current list as you read or handle them, with new matches added at the end.
- In manual order, drag sibling conversations or reorder folders within their pinned or regular groups. Newly created conversations and newly added folders start at the top of their group. The order survives a restart. Hold Shift while dragging a conversation to open it in split view.
- Worktree indicators stay with their conversation. Sidebar headings align across views, and long title lists do less layout work during scrolling and resizing. In narrow split panes the message index stays in the gutter and remains accessible by mouse and keyboard.

## Live replies and code

- Recent progress messages and tool activity stay visible while a reply runs. Earlier steps fold as the task grows. A completed turn folds its process when the final answer appears. Interrupted, failed and tools-only turns retain recent activity. Expanded long processes scroll continuously, with edge fades indicating more content.
- A single highlight moves across the running summary. Command, inspection and skill counts update as work proceeds, and pending approvals are identified. Opening, closing and reversing the transition are smoother and respect reduced motion. File changes show added and removed line counts before you open the diff.
- Paragraphs, code blocks and the reading position stay steady when a reply finishes. Scrolling back or using another pane preserves your place. Copying code retains line breaks and blank lines. Wrapping, expansion and keyboard focus carry over to the saved reply. Fast streams concentrate rendering on the text that is growing.
- The transcript marks a model switch on the turn that actually uses the new model. An open error detail stays visible when streaming ends. Reopened conversations retain the error code and, for an unavailable model, guidance on checking its upstream ID and reasoning level.

## Paused and interrupted tasks

- Quitting the app or restarting for an update saves received reply content and pauses local work. On launch, eligible tasks interrupted by a quit, update or crash are resumed in their original conversation and mode. Tasks you stopped stay stopped, and existing permission requirements still apply.
- An empty composer in a paused chat offers Continue. Typing or adding an attachment sends a new message directly. Queued messages wait for an explicit action, and retries preserve the original send. Interrupted turns show the tokens reported so far and indicate when the final cost has not been reported.

## Built-in browser and recording

- Search directly from the address bar, stop a page load, or use browser shortcuts. Command+F on Mac and Ctrl+F on Windows open a top-right find bar with match counts and navigation without shifting the page. Browser records lets you search tabs and history across one or all conversations and find downloads by filename.
- Take control from the bottom of an active page to keep its existing input and stop both running and queued AI actions there. Choose Allow AI control to hand it back. Tab recycling protects unfinished forms, edits and playing media. Independent popups and tab annotations are preserved, and annotation save failures can be retried.
- Download records retain their status and offer opening, revealing in a folder, cancellation or retry where applicable. Moved or deleted files are identified. Restoring an attachment page no longer repeatedly downloads it. Filename collisions and unavailable save destinations are handled.
- Give a tab recording a duration to stop and save it automatically. The timer, stop and takeover controls float at the bottom. The recording indicator, toolbar and conversation stay outside the captured video. Hiding the tab pauses recording. The saved clip contains the selected page’s visuals.

## Space, files and diagrams

- Space opens on saved content, with page templates and a read-only guide available from the creation menu. Large libraries load in pages, keep loaded rows on retry, and restore category and reading position after opening a resource. Refreshes preserve in-progress create, rename and move forms and the active discussion. Excel imports use the selected Space.
- Opening Office version history saves pending edits first. Preview a historical file and retry a failed read or restore. Loading an external version resets stale undo history. Copy all content is available for Space text documents and file tabs, including current drafts and full supported long files.
- Spreadsheet clicks and drag selections preserve the viewport. Long cell values scroll inside the value bar, while keyboard and search still reveal their targets. PDFs retain the previous frame until the zoomed page is ready, presentations fit the panel width, and embedded previews no longer interrupt divider drags.
- Chat, the canvas, file readers and rich editors reuse Mermaid renders. Mind maps fit the initial viewport more reliably. Navigation, source edits and theme changes avoid redundant layouts and stale previews. Code editors follow the workspace background and syntax colors.

## Chat models and 1M context

- OpenAI adds GPT-6.2 Astra and GPT-6.2 Sol, with image input, five reasoning levels from Low to Max, and long-context pricing. Use a Responses connection for tools. New chat connections enable one recommended model and let you reveal other choices. Preset roles can inherit an enabled model. Existing selections, disabled entries, custom mappings and pinned chats are preserved. Long model dialogs also keep their close control below the window title bar.
- Supported official OpenAI, Gemini and other routes use their recognized 1M context window by default. Main chats and subtasks follow their own models, including saved role mappings on older connections. Smaller windows, explicit opt-outs and custom connection limits are respected.
- Both Zhipu Coding Plan regions add GLM-5.4 with image input, 1M context and Low, High and Max reasoning. New connections recommend 5.4, and existing connections can enable it in model management. Usage shows the plan credit rates and honors custom prices. GLM-5.3 and 5.3-Flash remain available. Both regions have 1M model context. On new connections the automatic compaction window is 512,000 tokens for China and 1,000,000 for the international preset.

## Gemini reasoning, service tiers and images

- Gemini 4 adds Carbon, Hydrogen and Neon and updates context and pricing information for the existing Argon entry. Carbon and Argon offer Low, Medium and High. Hydrogen and Neon also offer XHigh. The Google API receives the structured thinking level. Compatible Antigravity gateways use the matching model ID advertised for the connection.
- Choose Standard, Flex or Priority on supported models. The 1.3.4 input and output pricing multipliers are 1×, 0.5× and 1.8× respectively. Estimates use the tier actually served and its rates unless you configure a custom multiplier. Continuation requests are priced individually, actual token counts stay separate, and incomplete billing information is marked unknown.
- The four existing Nano Banana models use their own aspect ratios, reference limits, resolutions and pricing in settings, generation and reference-image editing. Saved options survive restart. Usage counts generation attempts and estimates honor the configured billing multiplier.
- Nano Banana 2.1 offers Minimal, Medium (default) and High at 1K, 2K or 4K. Nano Banana 2 offers Minimal (default) or High at 512, 1K, 2K or 4K.
- Nano Banana 2 Lite offers Minimal (default) or High at 1K. Nano Banana Pro manages its own thinking and offers 1K, 2K or 4K.

## Settings and vault approvals

- Instant CLI settings update individual fields, preserve JSON drafts and other settings, and validate permissions and environment values. Saved thinking defaults apply to requests. Rapid voice-setting changes keep the latest choice. Browser data can be cleared for an identity with no open tab, with failures reported. Retired tool-assessment controls were removed. Memory model and budget settings remain available.
- Eligible vault lookups and verified SSH file reads can remember an approval until you quit Onevium. It is bound to the same requester, credentials, target and operation. Desktop, channel and scheduled-task approvals have separate scopes. Locking or sleeping suspends access. Stopping the approval or quitting clears it.

## Desktop startup, updates and upgrading

- Updates download in the background with a corner progress indicator. Once ready, you choose when to restart and install. On macOS, clicking the Dock again or opening the workspace from the menu bar during startup brings back the same ready window. Windows more reliably shows the main window on a normal launch and uses an opaque frame.
- Before upgrading from 1.3.3, quit the app and back up the complete data directory, including Space files, versions and recordings. First launch backs up and verifies the main database before migrating conversations and settings. Restore the pre-upgrade data copy to roll back to 1.3.3. This release also fixes opening the database after the model catalog upgrade.
- Installers are available for Apple silicon Macs, Intel Macs and Windows x64. Both macOS builds use the same Onevium signing identity as 1.3.3. To replace an ad-hoc test build with the same version number, install the official DMG manually once. Differential updates can reuse cached blocks and fall back to a full download.
