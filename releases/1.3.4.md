# Onevium 1.3.4 · Live replies, Gemini reasoning and GLM-5.4

[简体中文](1.3.4.zh-CN.md)

- Live replies keep the latest progress visible. Earlier steps fold as the turn grows, and the process folds when the final answer arrives. Code retains its line breaks when copied and its wrapping choice when the reply finishes.
- Added Gemini 4 chat models, more controls for Gemini image creation, and GPT-6.2 Astra and Sol. Supported models use 1M context by default. Gemini service tiers and reasoning levels follow the model, with configurable billing rates.
- Added GLM-5.4 to both Zhipu Coding Plan regions with image input, 1M context and three reasoning levels. Existing model selections and custom prices are preserved.
- Compatible Gemini gateways can select the advertised model for the chosen reasoning level. Expanded error details stay visible when a reply finishes.
- Filter sessions by status or model, drag them into a manual order, and send a new message directly from a paused chat. Browser recordings can stop at a set duration.

## Installation and upgrades

Check for updates in the app or download the installer for your computer. First launch backs up and upgrades the main database. To roll back, quit the app and restore a complete pre-upgrade data-directory backup. The macOS packages use the same Onevium signing identity as 1.3.3. Users of older ad-hoc test builds should install the official DMG manually once.
