# Onevium 1.3.0 — 全新工作区、Git 工作树、撤回与分支、图片生成、浏览器独立身份

Onevium 1.3.0 围绕项目、会话和成果重新设计了工作区，并新增 Git 工作树、撤回与分支、浏览器独立身份，以及在会话中生成和修改图片。

- **全新工作区：** 新的导航栏、侧栏和标签页把项目、会话和成果放在一起。浏览器、文件、终端和 Review 各有位置；预览需要空间时，可以把会话停靠到角落继续。[文件、终端与 Review](https://onevium.com/zh/docs/files-terminal-review)
- **Git 工作树：** 开发任务可在独立工作树中进行，再在 Review 中查看本轮改动、分支差异或整个工作区。多仓库项目可以选择相关仓库。[工作树](https://onevium.com/zh/docs/worktrees)
- **撤回与分支：** 从任意回复分支出新会话尝试其他方案，或回到之前的位置。先预览范围，再选择只撤回会话，还是同时恢复已记录的文件改动。[分支会话](https://onevium.com/zh/docs/projects-and-sessions#branch-chat) · [撤回](https://onevium.com/zh/docs/projects-and-sessions#rewind)
- **浏览器身份与密码：** 为每个浏览器标签选择身份，工作账号和测试账号互不干扰；可单独清除某个网站的数据，并填充已保存的密码。macOS 上可从 Chrome、Edge 或 Brave 导入 Cookie 和密码；导入 Cookie 不保证保持登录。[浏览器配置文件](https://onevium.com/zh/docs/browser-automation#profiles)
- **图片生成：** 连接支持的 OpenAI 或 Google Gemini 图像服务，从描述或参考图开始，圈选区域、添加批注、对比版本并保存结果。需要另行配置图像服务。[图片生成与画布](https://onevium.com/zh/docs/image-creation)
- **用量洞察与通知：** 按模型和连接查看用量与费用，含每日热力图、会话明细和图片生成费用。通知改为按类别设置，每类可单独选择系统通知和提示音。[设置与数据](https://onevium.com/zh/docs/settings-and-data)
- **上手更顺：** 首次启动会引导登录和模型配置；发送前缺少什么，Onevium 会直接说明。[第一个任务](https://onevium.com/zh/docs/getting-started) · [连接模型服务](https://onevium.com/zh/docs/providers)
- **稳定性：** 长会话渲染更快，切换会话不再抖动或卡住，内置浏览器白屏后可自动恢复。回复里引用的本地图片、视频和音频直接在正文中显示；点击文件链接会打开正确的文件，有多个同名文件时让你选择。

## 升级前请了解

完整升级步骤与恢复说明：[安装与更新 Onevium](https://onevium.com/zh/docs/installation#updates)。

- **不支持降级。** 1.3.0 会升级本地数据库和登录数据，1.2.3 无法读取。升级前会在 `~/.onevium/upgrade-backups/` 保留备份。
- **离线期限。** 许可证至少每 14 天需联网校验一次；离线更久后，联网即可自动解锁。
- **macOS 钥匙串提示。** 第一次使用浏览器已保存密码时，macOS 会请求允许访问"Onevium Safe Storage"；导入 Chrome 密码时会请求 Chrome 的存储密钥。
- **默认设置变化。** 从未选择过外观的用户，默认主题会改变；通知改用新的分类设置，旧的应用内提示开关不再生效；侧栏项目折叠状态会重置一次。
- **首次启动会在后台建立用量索引**，历史较多时用量页稍后才完整。
- **macOS 更新方式。** 如果应用内更新提示无法安装，请下载下方 DMG 替换应用。
