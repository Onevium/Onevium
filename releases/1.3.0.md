# Onevium 1.3.0 — Redesigned workspace, Git worktrees, rewind and branching, image generation, and browser identities

Onevium 1.3.0 redesigns the workspace around projects, conversations, and their results. It adds Git worktrees, rewind and branching, separate browser identities, and image generation and editing inside the conversation.

- **Redesigned workspace:** a new navigation rail, sidebar, and tabs keep projects, conversations, and results together. Browser pages, files, terminal, and Review each have a place, and the conversation can dock in a corner while a preview takes the room. [Files, terminal, and Review](https://onevium.com/docs/files-terminal-review)
- **Git worktrees:** run a development task in its own worktree, then inspect the current turn's changes, branch differences, or the whole workspace in Review. Projects with several repositories let you choose the one that matters. [Worktrees](https://onevium.com/docs/worktrees)
- **Rewind and branch:** start a new conversation from any reply to try another approach, or rewind to an earlier point. Preview the scope first, then rewind just the conversation or also restore recorded file changes. [Branch a reply](https://onevium.com/docs/projects-and-sessions#branch-chat) · [Rewind](https://onevium.com/docs/projects-and-sessions#rewind)
- **Browser identities and passwords:** choose an identity for each browser tab to keep work and test accounts apart, clear one site's data on its own, and fill saved passwords. On macOS, import cookies and passwords from Chrome, Edge, or Brave; imported cookies do not guarantee a signed-in session. [Browser profiles](https://onevium.com/docs/browser-automation#profiles)
- **Image generation:** connect a supported OpenAI or Google Gemini image service, start from a prompt or reference, mark regions, add notes, compare versions, and save the result. Requires a separately configured image service. [Image generation and canvas](https://onevium.com/docs/image-creation)
- **Usage insights and notifications:** see usage and cost by model and connection, with a daily heatmap, session details, and image generation cost. Notifications are now grouped by category, each with its own system notification and sound. [Settings and data](https://onevium.com/docs/settings-and-data)
- **Getting started:** first launch walks through sign-in and model setup, and Onevium explains what is missing before a message is sent. [Your first task](https://onevium.com/docs/getting-started) · [Model providers](https://onevium.com/docs/providers)
- **Reliability:** long conversations render faster, switching conversations no longer flickers or stalls, and the built-in browser recovers from blank pages. Local images, video and audio referenced in a reply now show inline, and a file link opens the right file or lets you choose when several match.

## Before you upgrade

Full upgrade steps and recovery notes: [Install and update Onevium](https://onevium.com/docs/installation#updates).

- **No downgrade.** 1.3.0 updates the local database and sign-in data in a way 1.2.3 cannot read. A backup is kept in `~/.onevium/upgrade-backups/` before the update.
- **Offline limit.** A license must be checked online at least once every 14 days. After a longer offline period, connect to the internet and Onevium unlocks automatically.
- **macOS Keychain prompt.** The first time you use saved browser passwords, macOS asks to allow "Onevium Safe Storage"; importing Chrome passwords asks for Chrome's storage key.
- **Changed defaults.** If you never chose an appearance, the default theme changes. Notifications use the new per-category settings; the old in-app notice switch no longer applies. Sidebar project folding resets once.
- **First launch indexes usage** in the background; the usage page fills in after a short while for large histories.
- **Updating on macOS.** If the in-app update reports that it cannot install, download the DMG below and replace the app.
