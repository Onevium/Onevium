# Onevium 1.2.1 — 更流畅的启动，更有条理的工作空间

1.2.1 改进启动与登录、会话整理、语音纠正、浏览器操作和 Claude Code 插件管理。提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。

## 启动与登录

统一的启动界面跟随主题色，在身份检查和工作空间准备期间保持连续。加载文字更易读；登录页为系统窗口按钮预留空间，并按窗口大小居中排列。邮箱验证码使用分格输入，支持粘贴和输满自动验证；完整激活码也会自动提交。这些界面调整保留原有身份与许可证校验。

## 整理会话

使用表情、颜色和可复用标签辨认会话，自定义标记、来源和活动状态的位置，调整侧栏字号与导航菜单顺序。会话信息整合项目、最近活动、关联自动化和浏览历史。

AI 标题整理支持明确选择单个会话或项目范围、预览建议、应用结果，以及重试失败的命名请求。手动标题受到保护。AI 命名为可选功能，使用配置的服务商时可能产生用量费用，请先检查设置再启用。

## 语音、文件与日常交互

- 可选的转写纠正加入词汇、纠正规则、模板，以及从符合条件的编辑中学习词语。仍可使用本地识别；可选 AI 纠正使用你配置的服务商。
- 听写过程中切换会话时保留转写内容，波形更清楚地反映说话节奏。
- 文件导航和媒体预览更清晰，超长粘贴文本可转为文本附件。
- 优化工具过程展开、滚动提示、会话标题与分屏交互。

## 浏览器、插件与模型

- 浏览器提供缩放、视口控制、超大预览平移和内置 Cookie 导入，菜单可正确显示在原生网页视图上方。
- 在扩展中心内浏览 Claude Code 插件市场、管理来源、安装和移除插件，并查看操作状态与错误。安装前请检查第三方插件的内容。
- 在支持的入口展示 CLI 内置技能，随包 Claude Agent SDK 更新至 0.3.278。
- 改善兼容第三方服务路径的提示前缀稳定性、子会话的服务商与模型选择，以及模型和推理强度展示。是否命中缓存仍取决于服务商。

## 升级提示与默认行为变化

替换应用前退出 Onevium，保持相同的系统用户和应用数据目录。首次启动自动升级数据；数据库结构需要迁移时，会先在本地 `upgrade-backups` 中创建快照。升级回归覆盖会话和服务商配置的保留。

部分可选 Agent 工具组现在需要明确开启。升级后如果会话、定时任务或回顾工具不可用，请检查能力设置；已有会话和定时任务不会因此删除。AI 标题整理仍需主动启用。新安装的浏览器运行能力默认关闭，已有启用设置会保留。Anthropic 默认模型列表聚焦较新的代际；如果服务商提示已保存模型不可用，请重新检查选择。

旧版应用会拒绝较新数据库结构。回退需要对应的升级前备份，并非无损降级：备份之后的改动不会恢复。不要通过删除应用数据来处理升级问题。

## 安装包与验证范围

- macOS Apple Silicon：`Onevium-1.2.1-arm64.dmg`
- macOS Intel：`Onevium-1.2.1-x64.dmg`
- Windows x64：`Onevium-Setup-1.2.1.exe`

同时提供 macOS ZIP、blockmap 和自动更新元数据，可用 `SHA256SUMS` 校验下载文件。应用完整性清单保护关键运行文件，与操作系统的发布者证书是不同层次的检查。

macOS 安装包采用 ad-hoc 临时签名，未做 Apple 公证，未使用个人开发者证书。Windows 安装包未做发布者证书签名。打包过程检查原生依赖、隐私泄漏、完整性签名和更新元数据；macOS Apple Silicon 执行打包后运行冒烟检查。此构建主机未实测 Windows、Intel 安装，以及旧版本差分更新的完整流程。
