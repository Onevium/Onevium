# Onevium 1.2.1 — A smoother start and a workspace you can organize

1.2.1 improves startup and sign-in, conversation organization, voice correction, browser controls, and Claude Code plugins. Available for macOS Apple Silicon, macOS Intel, and Windows x64.

## Startup and sign-in

A shared, theme-aware startup surface carries the app through identity checks and workspace preparation. Loading text is easier to read, and the sign-in layout reserves space for native window controls and centers the form at different window sizes. Email codes have individual cells, support pasting, and verify automatically when complete. Complete activation codes also submit automatically. These presentation changes retain the existing authentication and license checks.

## Organize conversations

Use emoji, colors, and reusable labels to recognize conversations. Customize the positions of markers, sources, and activity states, choose sidebar text size, and rearrange navigation entries. Conversation information brings together project context, recent activity, linked automation, and browsing history.

AI title organization supports explicit conversation or project scope, previewing suggestions, applying changes, and retrying failed naming requests. Manual titles remain protected. AI naming is optional and can incur usage with the configured provider; review its settings before enabling it.

## Voice, files, and everyday interaction

- Optional transcript correction adds vocabulary, correction rules, templates, and learning from eligible edits. Local recognition remains available; optional AI correction uses the configured provider.
- Switching conversations during dictation preserves the transcript. The waveform follows speech more clearly.
- File navigation and media previews are clearer; very large pasted text can become a text attachment.
- Tool activity disclosure, scroll cues, conversation titles, and split-work interactions receive further refinements.

## Browser, plugins, and models

- Browser zoom and viewport controls, panning oversized previews, in-place cookie import, and menus that remain visible above native web content.
- Browse Claude Code plugin marketplaces inside the extension center, manage sources, and install or remove plugins with visible status and errors. Review third-party plugins before installing them.
- Built-in CLI skills are visible where supported. The bundled Claude Agent SDK is updated to 0.3.278.
- More stable prompt prefixes on compatible third-party provider paths, improved provider/model selection for child conversations, and clearer model/effort details. Cache availability still depends on the provider.

## Changed defaults

Some optional agent tool groups now require explicit enablement. If conversation tools, scheduled-task tools, or recap tools are unavailable after upgrading, review the capability settings; existing conversations and schedules are not deleted. AI title organization remains opt-in. Browser runtime is off by default for new installations; an existing enabled setting is retained. The default Anthropic picker focuses on recent model generations; review a saved model if its provider reports it unavailable.

For update and backup instructions, see the [installation guide](https://onevium.com/docs/installation).
