# Onevium 1.3.2 — 有依据的记忆、浏览器身份与网络线路、菜单栏快捷中心

Onevium 1.3.2 重做了记忆：每条记忆都能看到来源和依据，回答里会标出用到了哪些记忆。内置浏览器支持多个身份，每个身份有独立的登录状态和网络线路。另外新增菜单栏快捷中心、会话通知和定时数据库备份，并接入千问和小米 MiMo。

- **有依据的记忆：** 记忆只从你说过的话和确认过的内容中提取，每条都能看到来源对话、依据和修改记录。所有记忆集中在「设置 → 个性化 → 记忆空间」，可以查看一条记忆和其他记忆的关联，以及它的使用次数和影响。回答用到记忆时会标出来，点开就能看到依据。删除、撤回和遗忘的效果更明确，遗忘的内容不会再被召回。1.3.1 的记忆全部保留，升级后向量索引会在后台重建，不需要重新下载模型。[记忆与回顾](https://onevium.com/zh/docs/memory-and-recap)
- **浏览器身份与网络线路：** 内置浏览器可以保存多个身份，每个身份有独立的 Cookie、登录状态和网络线路（HTTP / HTTPS / SOCKS5，支持账号密码）。新标签按会话记住所用身份；AI 不确定该用哪个身份时会先问你。网站权限请求改为 Chrome 式的气泡，登录时会询问是否保存密码。线路在「设置 → 网络」中统一管理。[浏览器自动化](https://onevium.com/zh/docs/browser-automation)
- **菜单栏快捷中心：** 从 macOS 菜单栏（Windows 托盘）打开快捷中心，可以查看等待确认、进行中和最近的会话，以及今天和近七天的用量；在同一列表中搜索并复制秘钥库里的验证码和密码；还可以生成密码，复制或保存过的密码会加密记录在本机历史中。图标上会显示等待确认的会话数。
- **通知与 Dock：** 会话完成、需要确认或出错时发送系统通知，可以按类别设置提示音和显示方式。Dock 菜单可以直接打开等待确认、进行中和最近的会话，窗口标题会跟随当前会话。
- **数据与存储：** 新增定时在线数据库备份和存储管理。大版本升级时，启动页会显示真实的升级进度（备份、校验、迁移）。
- **服务商与模型：** 新增阿里云千问（国内 / 国际 / Coding Plan）和小米 MiMo（含 Token Plan）预设；同步 2026-10-25 各服务商的最新模型，包括 Kimi K3.1 Pro、Gemini 4 Argon、MiniMax M3.1 Flash。使用 OpenAI 官方服务时会显示 GPT 的思考摘要。[服务商](https://onevium.com/zh/docs/providers)
- **图像与会话整理：** 图像模板支持分类，每张模板都有预览图，布局也做了调整。整理会话标题时会优先匹配已有标签。
- **系统权限：** 设置中集中显示录屏、麦克风、辅助功能等系统权限的状态，并提供恢复指引。
- **修复：** 登录刷新被中断或网关出错时不再退出登录；没有文字增量的原生回复不再丢失；Windows 上先正常关闭服务再强制结束；渠道里的权限请求只接受机器人允许名单中的用户回答；秘钥遮蔽不再截断转义序列；内置浏览器地址栏可以点击定位光标；导入 Cookie 时保留 host-only 属性，修复 Google 登录的 CookieMismatch；长回复的 Markdown 只渲染一次。

## 升级前请了解

完整升级步骤与恢复说明：[安装与更新 Onevium](https://onevium.com/zh/docs/installation#updates)。

- **首次启动会升级本地数据，不支持降级。** 1.3.2 会先备份数据库并校验，再升级数据格式。数据量大时可能需要几分钟，启动页会显示进度，请不要强制退出。升级后 1.3.1 无法直接读取新数据；升级前的备份保存在数据目录的 `upgrade-backups` 中。如需回退，先退出 Onevium，用备份替换 `onevium.db`，并删除同目录下的 `onevium.db-wal` 和 `onevium.db-shm`。
- **macOS：这一次需要手动安装。** 1.3.1 无法在应用内完成这次更新，请退出 Onevium，下载对应芯片的 DMG 替换应用。从 1.3.2 起，应用使用固定的「Onevium」签名（未经 Apple 公证），以后的版本可以在应用内更新。
- **macOS 权限与钥匙串。** 换成新签名后，需要重新授予一次录屏、麦克风和输入监控权限，之后的版本会保留这些授权。钥匙串不同：每个新版本第一次启动时，系统都会请求一次登录密码，请选择「始终允许」。拒绝不会丢数据，但保存的服务商密钥等内容会暂时读不到。
- **记忆：** 升级后后台会重建记忆向量，时间取决于记忆数量，期间仍可按关键词召回。记忆的模型调用现在按真实费用计入每日预算（1.3.1 只按写入条数粗略记账）：没有定价的自建连接按小模型价估算，人民币计价按汇率折算。从未设置过预算的早期安装，默认每日预算由 $0.10 调整为 $1；已设置的预算不变。若记忆提示“今日预算已用完”，可在「设置 → 个性化」中调高。
- **默认行为变化：**
  - 1.3.1 中开启了但地址或端口没填完整（或端口无效）的代理，会视为关闭，与 1.3.1 实际直连的效果一致。
  - ⌥⌘K 和 ⌥⌘T 不再默认占用，如需使用请在快捷键设置中绑定。
  - 菜单栏会出现快捷中心图标。
  - 渠道机器人的权限请求只能由允许名单中的用户回答。允许所有人私聊、但名单为空的机器人，请在「渠道」中添加允许的用户。
  - MiniMax 已下线的 Preview 和 M2.7 型号会改用 M3.1 Flash。
  - 原来用自定义连接接入千问或 MiMo 地址的，会自动套用新预设的兼容设置，未单独设置的角色会使用预设推荐的型号。
- **Windows 安装。** 可以在应用内更新，或运行下方的安装程序。安装程序未做代码签名，请确认来源和校验值后再处理系统拦截提示。Windows 上的安装、启动和覆盖升级尚未在真实 Windows 环境中验证。
