# Onevium 1.3.3 — 资料空间、浏览器录制与更顺手的 AI 协作

[English release notes](1.3.3.md)

Onevium 1.3.3 新增资料空间，把文档、表格、演示文稿、网页和相关讨论放在一起，并接入聊天右侧工作台。本版加入 Fable 5.2、GPT-6.1 Terra 和 GPT Image 2.6 系列支持，还带来浏览器录制、菜单栏实时确认和当前一轮的 Ultrathink。

## 模型与思考控制

- **Fable 5.2。** 新增模型选择、思考强度与用量计费信息，更新内置 Claude 运行时以适配新模型。思考强度支持从低到最高五档，默认中等；在支持的 Claude 连接中可使用单轮 Ultrathink 和独立的协作开关。
- **Mythos 5.2、GPT-6-Cyber 与 GPT-6 Rosalind。** 加入模型目录、相应能力和计费信息，并标明需要服务商授权。默认关闭，获得账号使用权限后可手动启用。
- **GPT-6.1 Terra。** 新增模型选择、思考强度、图像输入和工具调用适配；工具调用使用 Responses 连接。
- **GPT Image 2.6 Flare / Sunburst。** 加入图像创作模型目录，提供对应的生成选项与计费信息。
- **GPT-6 Astra 与 Kimi。** 补齐旧 OpenAI 连接中缺少的 Astra，更新思考选项；新建 Moonshot 连接的快速和子代理角色采用 Kimi K3.1 Pro，保留已有连接的模型映射和个人设置。
- **思考与协作分别控制。** 输入框保留思考强度滑杆，把单轮 Ultrathink 和自动协作收进高级选项；切换模型或连接时按实际支持能力显示，明确关闭协作时会遵循你的选择。

## 新功能

- **资料空间：资料有自己的位置和历史。** 创建空间、导入资料、编辑 Markdown 文档、添加评论并查看版本。每份资料可以独立打开，管理自己的附件与相关讨论；从会话保存的资料不依赖原会话继续存在。支持把整份资料或选中文本引用到聊天，并在会话信息中查看引用、读取、修改或保存过的资料。
- **表格、任务与办公文件。** 使用带字段、记录和视图的原生表格管理资料与待办；导入 Excel 时先检查字段映射。支持电子表格和演示文稿的受支持编辑操作、保存版本与预览。复杂 Office 内容保留原文件，并按实际支持范围提供编辑或预览；这不等于完整 Office 编辑兼容。
- **保存可交互的网页。** 网页资料可以保存入口文件与配套资源，查看文件、预览页面、浏览历史版本，并把修复需求交给关联讨论。保存快照与网页运行时访问外部资源的情况会区分显示。
- **聊天与资料共用工作台。** 在聊天右侧打开资料空间，继续使用资料的编辑、评论、版本与预览。切换资料或聊天时保留相应输入状态；资料保存后更新对应内容，有未保存草稿时保留本地编辑。
- **内置浏览器录制。** 录制当前标签页，支持暂停、继续、停止和保存；切换到不可见标签页时会暂停。录制文件可在存储设置中管理。每次录制最长 15 分钟，并有文件大小限制；这是浏览器页面录制，不是全桌面或音频录制。
- **菜单栏处理确认与两步验证码。** 在快捷中心直接查看并处理实时确认请求。两步验证码支持设置密钥、二维码和批量导入，包括受支持的 Google 身份验证器导出内容；导入前可检查账号对应的秘钥条目。
- **统一的权限与确认设置。** 按工具、浏览器、秘钥、SSH 等类别调整等待时间和超时处理，也可从确认卡片直接调整对应规则。渠道的完全访问模式会立即执行已接入消息中的操作，保留已有机器人的权限选择和发送者检查。
- **会话管理与运行记录。** AI 可在已有权限范围内创建、停止、移入回收站或恢复会话；会话信息直接展示代理历史、关联定时任务的执行结果和实际运行入口，方便继续跟进。
- **连接任务来源。** 资料空间的原生表格可连接会话任务，以及配置过权限的飞书任务清单、日历和钉钉待办；管理来源、拉取内容，并在支持的来源上回写完成状态。

## 用资料空间做每日复盘

社区新增官方 **每日复盘 · Daily review** Skill：从少量近期会话和你的明确反馈了解写作偏好，整理成果、决定和后续事项，并把可复用的经验单独积累到资料空间。日报可查来源、可继续编辑；配合定时任务，可以按你选择的时间自动执行。

安装后可以这样开始：“创建一个工作复盘资料空间。先了解我近期的沟通习惯，再把今天的工作整理成适合我的简短日报，保存到资料空间，并记录有依据的经验教训。”

## 改进与修复

- 改进长回复播放和切换会话时的稳定性，减少首次发送闪动；对插话未被接受和消息仍在排队的情况给出更明确的反馈。
- 子会话卡片更紧凑，显示模型与服务商信息；最近的子会话更容易找到，移除每个父会话的固定子会话数量上限。
- 文档与文件预览共用 Markdown 编辑体验，修复列表选区、表格输入、布局变化时的编辑状态和文档切换问题，并支持全窗口查看图表。
- 修复设置加载和保存的竞态，避免较晚返回的数据覆盖较新的编辑；配置未完整读取时保留草稿并显示错误。新增简洁的用户规则预设，工具加载说明更清楚。
- 改进浏览器身份、自动填充和下载处理，修复 Windows 凭据检查可能让会话卡住的问题。
- 图像创作、AI 工具和后台图像任务共用生成队列，支持批量请求和有限的限流重试；凭据暂时无法读取时给出准确反馈，避免误报为没有配置。修正 Nano Banana Pro 的比例选项，并按服务返回信息区分图像、文本和思考用量。
- 浏览器记住最近成功使用的身份；新的身份选择请求有独立倒计时。验证码详情支持元数据编辑和批量操作，保留未选中的条目及原有登录信息。
- 设置入口加入侧边导航及账号菜单，工具与代理等常用设置可以就地打开。
- 新安装可以通过应用内置的 Claude 运行时开始登录，并启用内置浏览器及更多工具组。新安装的界面、命名和工具默认设置不会覆盖已有安装的个人选择。

## 从 1.3.2 升级前请阅读

- **首次启动会升级主数据库。** 应用会先生成并校验升级备份，再迁移本地数据。请等待启动过程完成，不要强制退出。升级后的主库不能直接交给 1.3.2 使用。
- **保留升级前的数据副本。** 升级备份位于当前数据目录的 `upgrade-backups`。如需回退，先完全退出 Onevium，另存当前数据，再使用升级前的主库备份恢复 `onevium.db`，移走同目录旧的 `onevium.db-wal` 与 `onevium.db-shm` 后启动旧版本。回退不会保留升级后新增的主库数据。
- **资料空间需要单独纳入完整备份。** 资料空间的数据库、文件和版本保存在数据目录的 `space` 子目录。现有“数据库备份”保存主库，不能作为资料空间的完整备份。迁移设备或回退 beta 时，请完全退出应用后备份整个数据目录；不要只复制一个数据库文件。
- **每日简报的替代方式。** 原内置每日简报及其专用定时触发器已退役，旧记录保留在数据库中。现在可以从社区安装官方[每日复盘 Skill](https://github.com/Onevium/onevium-skill-community#每日复盘--daily-review)，先了解你的沟通习惯，再将适合你的日报与有依据的经验教训保存在资料空间。需要每天自动生成时，可以按自己的时间、项目范围和模型设置定时任务。首次使用需完成配置，旧简报任务不会自动迁移。
- **检查新的“权限与确认”规则。** 尚未保存新规则时，普通确认默认等待 30 秒后自动确认，提问默认等待 2 分钟后采用可用默认选项；必须填写的内容不会自动编造。原有秘钥超时拒绝设置会继续用于秘钥、SSH 和敏感操作。可以按类别调整等待时间和确认／拒绝行为；来源或渠道发送者未获授权时不会因此获得权限。渠道的“完全访问”模式会直接执行已接入消息中的操作。
- **模型与个人设置。** 升级追加新模型时保留已有模型选择、自定义配置和禁用状态；未使用、未自定义的受限目录模型可能被默认关闭，需要确认账号权限后手动启用。新安装的默认工具与界面设置不会强制套用到老用户。
- **macOS 更新。** 官方 1.3.2 与 1.3.3 使用同一固定 Onevium 签名。旧包缓存与 blockmap 可用时，应用内增量更新可复用未改变的数据块，必要时回退为完整下载；旧 ad-hoc 包需手动安装一次。可以在应用内检查更新；如需手动安装，请完全退出应用后用官方 DMG 替换。首次启动时，钥匙串访问可能需要重新允许。

## 使用范围

资料空间以本地资料管理为主，不提供云端多人共同编辑。文件读取与 AI 引用有格式及大小限制；扫描或加密 PDF、复杂 Office 嵌入内容、音视频内容分析不能视为已完整读取。飞书、钉钉等外部来源需要单独配置连接和相应权限。
