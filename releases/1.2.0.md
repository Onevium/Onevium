# Onevium 1.2.0 — A clearer view of your work

**A major interface update for macOS and Windows**

1.2.0 is a major interface redesign shaped around everyday work. We revisited the visual structure of projects, conversations, the composer, browser previews, settings, and information panels—giving familiar features a more consistent presentation and the content more room to speak.

The result is a clearer, more personal Onevium for the work you return to every day.

## A more considered workspace

Coordinated palettes, typography, spacing, and control states bring the interface together. Complex content has a clearer hierarchy, while typing and switching context feel less visually intrusive.

- Built-in palettes for both light and dark workspaces.
- Refined conversation, project, settings, and preview layouts.
- Subtler focus treatments for the address bar and model filter.
- Better alignment and consistent sizing for macOS titlebar sidebar icons.

## A browser that stays with the task

Pages have a clearer connection to the conversation they belong to. A dedicated shortcut helps you return to the browser and revisit earlier pages.

- Per-conversation browsing history, title and URL search, and progressive loading.
- A browser shortcut beside permissions for history and reopening pages.
- Browsing history inside conversation information.
- A wider address bar and consistent loading, timeout, and unavailable-page states.
- A fix for retries that could fail to reload the same URL after a connection error.

## Better details for split work

Dragging, switching, and checking context are small actions that happen all day. This update gives them more attention.

- Information overlays step aside during conversation dragging and split-column reordering.
- Information-card visibility is saved independently for each conversation.
- Improved model-selection retention, preference persistence, and new-conversation layout.

## Diagrams, skills, and settings

- Improved Mermaid loading, diagram enlargement, and source-canvas editing.
- Reorganized plugin and settings interfaces for finding and managing capabilities.
- Start from a skill detail page with an editable conversation draft in the selected project. You decide when to send it.
- Refinements to native-model usage accounting and reasoning configuration.

## See the workflow

Keep development conversations beside page previews, or bring a concise business analysis together with its charts. Existing Feishu, DingTalk, Discord, and WeChat support also brings recognizable channel context into project and channel views.

## Upgrading and availability

1.2.0 replaces the planned 1.1.24 version number. Install the matching macOS Apple Silicon / Intel DMG or Windows x64 installer. macOS ZIPs and Windows blockmaps remain available for the updater; the Windows differential-update format is retained.

Close running tasks and quit Onevium before replacing the app. Keep the same OS user and data directory. Existing conversations and settings are migrated automatically at startup; an existing database that needs a schema upgrade receives a local snapshot in `upgrade-backups`. Do not manually delete your app data. Returning to an older app is not a lossless downgrade: new browser history may be lost, and restoring a database backup discards changes after that snapshot.

This release also improves heavy-conversation switching: the target context appears before expensive transcript work, then history mounts in smaller batches. Agent progress remains visible in compact cards. Empty external-access onboarding, provider-form scrolling, subtle dark popover borders, and text-field focus states are refined.

**Compatibility notes:** macOS builds are not notarized; follow the official installation guide if macOS asks for confirmation. No personal developer certificate is used. Windows x64 packages and updater metadata are verified during packaging; a real Windows old-version differential installation has not been exercised on this macOS build host. Very large individual messages can still require rendering time.
