# Onevium 1.2.2 — 文件处理、后台工作与 MCP 控制

Onevium 1.2.2 让更多文件操作直接在会话中完成，改进后台会话和 MCP 控制，并扩充可选模型目录。

- **工作区文件：** 从聊天中的本机文件引用直接打开文件。Markdown、文本和 CSV 支持编辑，CSV 可网格预览；PDF、Word、PowerPoint 和 Excel 文件提供只读预览。
- **附件输入：** 粘贴、拖入和选择文件时，引用更稳定；重新编辑排队消息会保留文字和原图。
- **后台工作：** 主会话中断后，任务和子会话仍可继续。子会话按父会话归组，并发名额只计算正在运行的工作。
- **MCP 控制：** 可按全局、项目或会话范围控制启停、工具白名单和按需加载；查看 schema 与上下文占用估算，并导出 CLI 配置。
- **Review：** 改善跨仓库分支比较、预览和差异批注，仓库切换与导航更顺畅。
- **模型：** 可选目录新增 Grok 4.7、Claude Opus 5.5、GPT-6 Sol 和 Luna，修复模型路由与已保存自定义选择的兼容问题。
- **浏览器控制：** 改善表单输入、日期、弹窗、首次页面加载和后台视图操作；console 与 network 记录更易检查，操作状态在整个聊天回合保持可见。
- **日常修复：** 修复部分自动标题误写成附件引用的问题，改进单轮费用记录和频道会话命名，并在切换会话时保留听写内容。
