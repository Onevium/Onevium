# Onevium

### 로컬 우선. 일상 업무에 AI를 연결하세요.

**Local-first(로컬 우선)** 데스크톱 AI 작업 공간입니다. 여러 모델, 브라우저, 파일, 업무 도구를 하나의 프로젝트에 모아 코드 작성, 자료 조사, 이미지 제작을 진행하면서 결과를 확인하세요.

**[Onevium 다운로드](https://github.com/Onevium/Onevium/releases/latest)** · [시작하기(영어)](https://onevium.com/docs/getting-started) · [새로운 기능(영어)](releases/1.3.2.md)

macOS(Apple Silicon 및 Intel) · Windows x64

**[@Onevium](https://github.com/Onevium)** 을 팔로우하고 제품 소식과 실용적인 AI 워크플로를 만나보세요.

</div>

*스크린샷은 실제 UI 구성 요소를 사용하는 별도의 1.3.0 개발 데모 환경에서 촬영했습니다. 프로젝트, 대화, 보고서는 모두 가상 데이터입니다.*

## 개인 프로젝트에서 기업의 일상 업무까지

Onevium은 이미 **고객 서비스, 물류, 크로스보더 광고 분야의 기업**에서 사용하고 있습니다. 기존 모델 서비스, 계정, 업무 도구를 연결하고 팀에 맞는 워크플로로 조합할 수 있습니다.

## 모델과 서비스를 직접 선택하세요

| 유형 | 지원 연결 |
| --- | --- |
| 글로벌 모델 서비스 | Claude / Claude Code, OpenAI GPT, Google Gemini, xAI Grok |
| 중국 모델 서비스 | DeepSeek, GLM / z.ai, Kimi / Moonshot, MiniMax, Alibaba Cloud Qwen, Xiaomi MiMo |
| 사용자 지정 서비스 | 호환 API를 제공하는 서비스 또는 팀 모델 게이트웨이에 URL, 인증 정보, 모델 ID를 직접 설정해 연결 |
| 이미지 생성 | OpenAI 또는 Google Gemini 이미지 서비스를 별도로 설정 |

같은 대화에서 모델을 전환하거나 협업 팀 구성원별로 모델을 선택할 수 있습니다. 사용 가능한 모델, 도구 기능, 비용은 연결한 서비스와 계정 권한에 따라 다릅니다. Onevium 계정 및 라이선스와 모델 서비스 이용 권한은 별개입니다. [연결 안내(영어)](https://onevium.com/docs/providers).

**로컬 중심의 작업 환경, 서비스는 직접 선택.** 프로젝트 파일, 대화, 작업 자료는 내 컴퓨터를 중심으로 관리하고, 저장한 인증 정보는 로컬에서 암호화합니다. 클라우드 모델, 이미지 서비스, 메시징 채널을 이용할 때는 관련 내용이 설정한 서비스로 전송됩니다.

## Onevium 다운로드

**현재 안정 버전: 1.3.2.** [변경 사항 및 업그레이드 안내(영어)](releases/1.3.2.md).

| 플랫폼 | 다운로드 |
| --- | --- |
| macOS · Apple Silicon | [arm64 DMG 다운로드](https://github.com/Onevium/Onevium/releases/download/v1.3.2/Onevium-1.3.2-arm64.dmg) |
| macOS · Intel | [x64 DMG 다운로드](https://github.com/Onevium/Onevium/releases/download/v1.3.2/Onevium-1.3.2-x64.dmg) |
| Windows · x64 | [EXE 다운로드](https://github.com/Onevium/Onevium/releases/download/v1.3.2/Onevium-Setup-1.3.2.exe) |

**1.3.2로 업그레이드하시나요?** macOS에서는 Onevium을 종료한 뒤 DMG로 이번 업데이트를 수동 설치해야 합니다. 처음 실행할 때 로컬 데이터가 업그레이드되며, 1.3.1은 업그레이드된 데이터를 직접 읽을 수 없습니다. 업데이트 전에 [업그레이드, 서명 및 복구 안내(영어)](https://onevium.com/docs/installation#updates)를 읽어주세요.

현재 안정 버전에는 Linux 또는 Windows arm64용 설치 파일이 없습니다. 설치 후 계정 로그인 또는 라이선스 활성화를 완료하고, 사용 가능한 모델 서비스를 연결하세요. [설치 및 호환성(영어)](https://onevium.com/docs/installation) · [기업 및 팀 문의(영어)](https://onevium.com/pricing).

## 명령어로 설치하기

<details>
<summary><strong>macOS 및 Windows 설치 명령어 펼치기</strong></summary>

**macOS · Apple Silicon / Intel** — 터미널에 다음 명령어를 붙여 넣으세요.

```sh
curl -fsSL https://raw.githubusercontent.com/Onevium/Onevium/main/install/install.sh -o onevium-install.sh && sh onevium-install.sh
```

설치 도우미가 CPU 아키텍처를 감지하고 공식 안정 버전 설치 파일을 다운로드한 뒤 SHA-256을 확인하여 설치 화면을 엽니다. Onevium을 응용 프로그램 폴더로 드래그하면 설치가 완료됩니다. 업데이트 전에 실행 중인 Onevium을 종료하세요.

**Windows x64** — PowerShell에서 실행하세요.

```powershell
$p = Join-Path $env:TEMP 'onevium-install.ps1'; Invoke-WebRequest 'https://raw.githubusercontent.com/Onevium/Onevium/main/install/install.ps1' -OutFile $p -UseBasicParsing -ErrorAction Stop; & $p
```

현재 실행 정책에 따라 도우미를 저장하고 실행하며, 설치 파일을 검증한 뒤 설치 마법사를 엽니다. 정책에 의해 스크립트 실행이 차단되면 설치 파일을 직접 다운로드하세요.

[도우미 확인, 버전 지정 및 자세한 설치 안내(영어·중국어)](install/README.md).

</details>

## 자유롭게 조합하는 주요 기능

- **여러 모델과 팀 협업.** 대화 중 모델을 전환하고, 구성원별로 모델과 작업을 지정해 조사, 실행, 검토를 하나의 흐름으로 연결하세요.
- **브라우저 프로필 × 독립 네트워크 경로.** 계정별로 쿠키, 로그인 상태, 네트워크 경로를 구분해 저장하세요. HTTP, HTTPS, SOCKS5를 지원하며 작업에 맞는 프로필을 선택할 수 있습니다.
- **비밀 정보 및 호스트 관리.** API, 데이터베이스, SSH 인증 정보를 내 컴퓨터에 암호화해 저장하세요. AI는 이름으로 참조하고 승인 설정에 따라 사용하며 출력의 알려진 비밀 값을 마스킹합니다.
- **SSH 원격 작업.** 한 번, 일정 시간 또는 세션 단위로 권한을 부여하고, 허용된 범위 안에서 서버 명령 실행과 파일 읽기·쓰기를 맡길 수 있습니다.
- **업무 및 메시징 도구 연결.** Feishu, DingTalk, Discord의 그룹 채팅과 개인 메시지, WeChat 개인 메시지를 연결하세요. 기존 소통 도구에서 프로젝트 도우미에 작업을 요청하고 결과를 받을 수 있습니다.
- **Skills × MCP × 플러그인.** 팀의 절차를 재사용 가능한 스킬로 정리하고 업무 도구를 연결해 프로젝트와 작업에 맞게 조합하세요.
- **예약 자동화 및 알림.** Onevium이 실행 중일 때 반복 작업을 수행하고, 대화 완료, 확인 요청, 오류 알림을 받을 수 있습니다.
- **근거를 추적할 수 있는 메모리.** 원본 대화, 근거, 변경 기록을 확인하세요. 답변에서 사용된 메모리를 추적하며 작업을 이어갈 수 있습니다.

**조합 예시:** Feishu에서 작업 수신 → 모델 선택 또는 팀 구성 → 적절한 브라우저 프로필과 프록시로 업무 페이지 접속 → 허용된 범위에서 인증 정보와 파일 사용 → 결과를 요약해 채널에 답변. 필요한 서비스와 권한을 먼저 연결한 뒤, 검증한 절차를 Skill이나 예약 작업으로 정리할 수 있습니다.
