## New in 1.2.2

- **Work with files beside the conversation.** Open local file references, edit Markdown, text, and CSV, and preview PDF, Word, PowerPoint, and Excel files.
- **Keep delegated work moving.** Background tasks and child conversations can continue after the main conversation is interrupted; child conversations stay grouped with their parent.
- **Choose the tools a task needs.** Control MCP availability, tool allowlists, and on-demand loading by global, project, or conversation scope.
- **Use updated models and clearer controls.** Optional Grok 4.7, Claude Opus 5.5, and GPT-6 Sol/Luna entries join the catalog, with browser form handling and multi-repository Review improvements.

## Small interactions, thoughtfully improved

- **Return to the page you were working on.** Each conversation keeps its own browsing history, with search, progressive loading, and quick reopening.
- **Make room for split work.** Information cards step aside during conversation dragging, and visibility preferences remain independent for each conversation.
- **A quieter place to type.** A wider address bar and subtler focus treatments make browser input and model filtering less visually intrusive.
- **Bring diagrams and skills into the task.** Diagram presentation and editing continue to improve. Start from a skill detail page with an editable draft in the selected project.

## Start with one concrete task

1. Download the [current installer](https://github.com/Onevium/Onevium/releases/latest) for your platform.
